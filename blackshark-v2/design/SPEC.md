# 给肥鱼（DSH）的视觉规格

视觉已经由本次开发确定，接收方优先修复连接与实机差异。不要依据日志重新创造一套界面。

## 布局与素材

| 项目 | 数值／规则 |
| --- | --- |
| 页面 | 固定 60px 顶栏；左侧设备名称、状态、透明商品图、配色色块、菜单；右侧设置框 |
| 侧栏宽 | 窗口宽度 >1100px：320px；721–1100px：240px；≤720px：180px |
| 菜单按钮 | 40px 高；宽分别 272／208／156px；8px 圆角 |
| 右框 | 12px 圆角；内容在框内滚动；禁止整个页面横向溢出 |
| 主色 | `#226bee`；选中、滑块、焦点使用同一色 |
| 亮色 | 背景 `#ffffff`；框 `#f2f3f7`；配置 `#ffffff`；正文 `#151515` |
| 暗色 | 背景 `#0c0c0c`；框 `#141414`；配置 `#1a1a1b`；正文 `#ffffff` |
| 字体 | Microsoft YaHei → system-ui → sans-serif；不打包原厂字体 |
| 产品图 | 用户提供的透明 PNG：G309 黑／白，BlackShark 黑／绿／白；原图字节与透明通道保留，尺寸／SHA256 见各设备 ARTWORK.json |
| 首页 | 克隆原厂 `.device-card`，跟随模板的 `is-list`、`is-dark`、`is-frosted-glass`；不另做统一大小的替代卡片 |
| 配色按钮 | G309 两色，BlackShark 三色；首页点击配色按钮循环，设置页点击对应色块；选择持久化且返回首页后同步 |
| 主题 | 初始 `dcTheme` 参数；之后宿主更新根元素 `data-dc-theme`，不重载页面 |

G309 菜单固定为「性能设置」「连接与电量」「设备信息」。BlackShark 固定为「声音输出」「麦克风」「均衡器（可选）」「声场与扩展」「设备信息」。

## 控件状态

设备连接未知时，读数为 `—`／未知，写入控件禁用。写入期间禁用重复提交，成功后显示回读值。失败时清掉本页连接状态并显示错误；不把用户刚选的值冒充设备当前值。

EQ 可以在离线页面编辑草稿；没有目标 USB 输出端点时，生成／保存按钮禁用。十段顺序：31、63、125、250、500、1k、2k、4k、8k、16k Hz。范围 ±12dB，步长 0.5dB。窄窗口只允许 EQ 控件自身横向滚动。导出的配置区必须写「已生成 · 未启用引擎」或「已保存 · 效果待验证」，不能写成音效已生效。

## 不看截图也能检查

`layout-report.json` 保存 DOM 几何和背景色，所有坐标来自离线浏览器实测。`previews/` 是同一代码的实际渲染图。`home-*-fixture.png` 使用原创结构测试样式，验证克隆与列表切换，**不是官方首页的实机截图**；原厂实际卡片尺寸仍由接收机器安装的 CSS 决定。

在完整仓库安装 Playwright 后，运行 `node tests/visual-handoff.cjs`。它检查两设备三种宽度与亮暗主题、全部菜单、十个 EQ 滑块、首页两种布局的标记与几何，以及模拟 API 的提交、确认和失败状态。模拟接口只存在于测试，截图默认使用未连接状态。

实际 M HUB 中另查：两个 `[data-dc-local]` 节点是否继承模板列表／主题类；右侧原生视图是否覆盖主窗口内容区；返回和 Esc 是否回到首页；主题切换不能闪成白底；拖动／选择中不得被定时刷新打断。
