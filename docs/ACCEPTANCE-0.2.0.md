# 0.2.0 发布验收记录

日期：2026-10-22。设备：Logitech G309、有线 BlackShark V2 原配 USB 声卡。

- 设备功能：项目主人反馈，对方已验证基础技术与功能可用，没有提交新的代码改动。该反馈作为本次发布依据；未取得逐项硬件测量数据。
- App 视觉：两张卡片以独立 ZIP 安装到项目主人的正式 MCHOSE HUB，与原三张卡共存，部署文件哈希已验证。项目主人随后明确表示验收完成，并授权发布主仓库、关闭两个开发 Issue。
- 本机清理：按要求取消 G309、BlackShark 两张卡片的注册，保留 keyboard、razer、charger 以及用户数据；正常重新启动 App。
- 自动检查：7 项 Node 合约与公共库测试、10 项 Python 设备后端夹具通过；隔离 EQ 配置的启用、重复启用、撤销与原有配置保留通过。发布构建校验全部清单文件哈希与 PowerShell 语法。
- EQ 交付：Equalizer APO 1.4.2 官方 x64 安装器、对应官方完整源码与许可现已随耳机独立包提供，文件 SHA256 与官方 SourceForge 元数据相符。Install-EQ 入口在启动前校验文件，按用户选择安装，再启用现有配置桥接。

开发与本次视觉验收完成。可选 EQ 的真实频响、G309 全部蓝牙能力、长期使用及未来厂商更新不包含在逐项测量结论中。EQ 仍按需启用；本次没有在验收电脑安装音频引擎。没有将保存配置等同于声音效果已测量。

原交接清单保留用于后续排错及扩展，未测项目不自动勾选。Issues #1、#2 依据项目主人确认标记开发完成。
